Sunset Bay is an open-world crime game in a sunny fictional coastal city. Explore on foot or behind the wheel, steal cars, dodge the police as your wanted level climbs, and run four story missions for the fixer Marla — from a parcel run to a bank score — with traffic, pedestrians, combat, a minimap and a full HUD.
## Run it
```sh
node serve.ts
# then open http://localhost:8080
```
